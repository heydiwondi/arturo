# Veni cùmmia — redesign elegante

Landing page responsive in HTML/CSS/JS, ispirata all'approccio editoriale/minimal del riferimento indicato, ma con identità propria.

## Struttura
- `index.html` — struttura e contenuti
- `styles.css` — design responsive, palette bianco/nero/oro
- `script.js` — menu mobile, header sticky e anno dinamico

## Personalizzazione immediata
1. Sostituisci gli URL delle immagini Unsplash con le foto reali dello Chef.
2. Sostituisci i link `https://wa.me/?text=...` con il numero WhatsApp reale.
3. Se necessario aggiungi Privacy Policy/Cookie Policy e tracking.
4. Per pubblicare: carica i tre file su hosting statico (Netlify, Vercel, Aruba, cPanel, ecc.).

Nota: i contenuti testuali sono quelli forniti dal cliente. Il layout è originale e non replica il codice o gli asset del sito di riferimento.
